# Python - Input/Output

This project covers file handling, JSON serialization and deserialization,
object serialization, command-line persistence, Pascal's triangle, file
search/update operations, and log parsing in Python.

## Learning Objectives

- Read UTF-8 text files
- Write and append to files
- Use the `with` statement
- Serialize Python objects with JSON
- Deserialize JSON into Python objects
- Save and load JSON files
- Convert object attributes to dictionaries
- Rebuild object attributes from dictionaries
- Work with command-line arguments
- Generate Pascal's triangle
- Update files by matching text
- Parse log data from standard input
