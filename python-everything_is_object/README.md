# Python - Everything Is Object

This project explores how Python handles objects, references, identity,
mutability, immutability, aliases, lists, tuples, strings, integers,
and object memory behavior.

## Learning Objectives

By completing this project, I should be able to explain:

- What an object is in Python
- The difference between a class and an object/instance
- The difference between immutable and mutable objects
- What a reference is
- What assignment does
- What an alias is
- How to check whether two variables are identical
- How to check whether two variables have equal values
- How Python passes variables to functions
- How lists behave when they are modified
- How tuples and integers are handled in CPython
- How `__slots__` can restrict instance attributes
