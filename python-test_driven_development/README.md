# Python - Test-Driven Development

This project practices Python development using doctests and unittests.

## Learning Objectives

- Write and run doctests
- Write unit tests with `unittest`
- Test edge cases and invalid input
- Document modules and functions
- Validate matrix data
- Perform matrix multiplication
- Use NumPy for matrix multiplication

## Required Files

- `0-add_integer.py` and `tests/0-add_integer.txt`
- `2-matrix_divided.py` and `tests/2-matrix_divided.txt`
- `3-say_my_name.py` and `tests/3-say_my_name.txt`
- `4-print_square.py` and `tests/4-print_square.txt`
- `5-text_indentation.py` and `tests/5-text_indentation.txt`
- `tests/6-max_integer_test.py`
- `100-matrix_mul.py` and `tests/100-matrix_mul.txt`
- `101-lazy_matrix_mul.py` and `tests/101-lazy_matrix_mul.txt`

`6-max_integer.py` is included so the unittest can run locally.
